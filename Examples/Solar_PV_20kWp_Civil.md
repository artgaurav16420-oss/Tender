# TENDER SPECIFICATION FOR SOLAR POWER SYSTEM WITH CIVIL WORKS

### 1. Scope of Supply

Procurement of 20 kW On-Grid Solar PV System with overhead mounting shed and associated civil works for RRCAT, Indore. The Bidder has to quote for complete 1 set for following items listed below:

|  |  |  |
| --- | --- | --- |
| Item No. | Item Description | Qty |
| 1 | Solar PV Plant, 20 kWp, 3-phase, on-grid with net-metering | 1 set |
| 2 | Solar Mounting Structure: Overhead shed, 15 ft clear height | 1 set |
| 3 | Foundation for shed on bare land associated civil work | 1 set |
| 4 | Installation, Testing and Commissioning | - |

### 2. Bidder Qualification Criteria (BQC)

**2.1 Equipment Manufacturer:** - Only OEM or their authorized dealers are allowed to bid in this tender.

**2.2 Quality Certifications:** The OEM must hold valid **ISO 9001** certification.

### The bidder has to do necessary civil work for site preparation on RRCAT bare land including foundation, concrete flooring and shed construction. Labor and materials required for these civil works is in the scope of the supplier.

### The bidder shall submit a copy of the valid ALMM Enlistment Letter issued by MNRE at the time of bid. The letter must verify that the specific Model Numbers and Manufacturing Unit address proposed for this project are enlisted in ALMM List-I. The validity of the enlistment must cover the entire scheduled supply period.

### 4. Bid Evaluation Criteria

The bidder must provide following documents/information for bid evaluation:

1. Vendor Compliance Sheet (signed & sealed)
2. Make & Model Nos of each component. The make & model number must be verifiable from OEM website/catalogue.
3. Technical Datasheets (solar module and Inverter)
4. OEM Authorization Letters (modules, inverter)
5. GA Drawings (shed, foundation)
6. Solar Yield Simulation Report (PVSyst)

### Failing to the below acceptance criteria will result in rejection of the delivered product. RRCAT will not bear any cost associated with the rejected product, including transportation, freight, handling, or return shipment charges.
