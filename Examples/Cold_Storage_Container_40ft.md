# TENDER SPECIFICATION FOR COLD STORAGE CONTAINER

### 1. Scope of Supply

Procurement of Cold Storage Container (4 TR, 4°C) for RRCAT, Indore. The Bidder has to quote for complete 1 set for following items listed below:

|  |  |  |
| --- | --- | --- |
| Item No. | Item Description | Qty |
| 1 | 40 ft Brand New Dry Shipping Container (ISO standard) | 1 No |
| 2 | Internal PUF Insulation (walls, floor, ceiling) +SS 304 internal finish | 1 set |
| 3 | Refrigeration Unit, 2 TR capacity | 2 Nos |
| 4 | Accessories for Cold Storage | 1 Set |
| 5 | Installation, Testing and Commissioning | - |

The bidder has to modify a standard 40 ft dry shipping container to thermally insulate it from inside and install refrigeration unit in it with other accessories required for cold storage.

###

### 2. Bidder Qualification Criteria (BQC)

**2.1 Equipment Manufacturer:** Only Cold Storage OEM or their authorized dealers are allowed to bid in this tender.

**2.2 Quality Certifications:** - The OEM must hold valid **ISO 9001** certification.

### 4. Bid Evaluation Criteria

The bidder must provide following documents/information for bid evaluation:

1. Vendor Compliance Sheet (signed & sealed)
2. Make & Model Nos of each component. The make & model number must be verifiable from OEM website/catalogue.
3. Technical Datasheets (refrigeration)
4. OEM Authorization Letters
5. GA Drawings (container)

### 5. Acceptance Criteria:

|  |  |  |
| --- | --- | --- |
| System | Test Protocol | Acceptance Criteria |
| Cold Storage | 1. Cool-down test from ambient to 4°C 2. 24-hour hold at 4°C ±1°C with doors closed | 1. Temperature stability ±1°C for 24 hrs 2. No compressor short-cycling |
